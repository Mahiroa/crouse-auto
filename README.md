# 雨课堂刷课助手

> 一个跑在浏览器里的油猴脚本（Userscript）：把雨课堂里「视频 / 音频 / 课件 / 图文 / PDF / 作业 / 测验 / 讨论」按顺序自动做完，
> 进度以平台自己的记账为准，而不是「播放器播到头了」。
>
> 当前版本 **3.6.2** · 作者 **Mark** · 许可证 **GPL-3.0** · 35 个模块拼装的单文件脚本

---

## 1. 这是什么

在雨课堂的课程学习页注入一个可拖动的控制面板，点「开始刷课」之后，脚本接管播放器并按目录逐节推进：

- 视频自动播完就换下一节，倍速与静音按设置执行，被平台改回去会自动重设；
- 课件（PPT / 课件内视频）按设定间隔翻页、等内嵌视频播完；
- 图文、PDF、讨论这些「点开即完成」的节点，打开后等平台记账；
- 视频播到头但平台没记满时，按平台的观看日志算出**真实缺口**，逐段补播再核对。

也可以只当个「倍速 + 静音 + 进度查看器」用：面板里的倍速/静音/快速模式随手可切，不点开始就不会接管流程。

**它不是**：不是考试代做工具（考试/补考一类的节点脚本明确不代做，只在收尾时点名提醒），不是刷分器，
也不会把任何数据发到作者自己的服务器（见 [§7 数据与隐私](#7-数据与隐私)）。

## 2. 功能一览

| 能力 | 说明 |
|---|---|
| 自动串播 | 视频、音频、课件、图文、PDF、作业、测验、讨论按目录顺序推进；课件视频关闭/销毁会自动重开重播 |
| 播放器接管 | 默认 **2 倍速 + 静音**；可设 0.25–4 倍速；暂停就拉回、倍速被改就重设，播完立刻进下一节 |
| 进度以平台为准 | 调平台接口读课程目录、单节进度与观看日志，`rate` = 已观看区间并集，≥ 99.9% 才算满 |
| 缺口补刷 | 按 `/video-log/detail/` 的区间表定位「哪几段没看」，逐段 seek 过去真播，播完复读日志核对；没涨就退 1 倍速再试一轮 |
| 断点续跑 | 跨页跳转（进课程 → 回目录）后自动恢复刷课，不用重新点开始 |
| 刷完结论 | ai-workspace 链路刷完会撒彩带 + 弹窗；**三分支分开**：真刷完 / 只剩考试类手动节点 / 真没刷完（列出还差哪几节、平台各多少） |
| AI 答题（可选） | 作业与测验读题 → 模型作答 → 自动点选项；支持 OpenAI / Anthropic 两种接口格式、Bearer / X-API-Key 两种认证，默认 DeepSeek |
| 截图识题（可选） | `html2canvas` 截图给多模态模型；模型不支持图片时自动退回本地 OCR（`tesseract.js`） |
| 字体混淆还原 | 考试类页面的 `exam_font` 自定义字体，用 `opentype.js` 读字形、按 SHA-1 对照表还原成正常文字 |
| 讨论/图文回复（可选） | 生成一句话填进发言框；超出题目要求长度时不截断残句 |
| 人机验证闸门 | 检测平台安全核验（滑块/安全验证）弹窗，两种策略：**跳过当前章节**（默认）/ **停下等待** |
| 切屏拦截兼容 | 拦住 `visibilitychange` / `blur` / `pagehide`，伪造 `hidden`、`visibilityState`、`hasFocus`，连作业所在的 iframe 一起处理 |
| 全屏兜底 | 页面进全屏时把面板搬进全屏层继续可见；`<html data-ykt-helper="版本号">` 留痕，用来区分「脚本没跑」和「跑了但面板被盖住」 |
| 面板 | iframe 独立 DOM，可拖动 / 缩放 / 缩成气泡；状态徽标、刷课轨迹（最近 60 项）、运行日志、清除进度缓存、重载并继续 |

## 3. 支持的页面

| 站点 | 页面 | 刷课流程 |
|---|---|---|
| `*.yuketang.cn` | `/ai-workspace/lms-graph/*` | `AiWorkspaceRunner`（主链路，功能最全） |
| `*.yuketang.cn` | `/v2/web/*` | `V2Runner`（v2 目录页，500 轮硬上限防死循环） |
| `*.yuketang.cn` | `/pro/lms/*` | `ProNewRunner` / `ProOldRunner`（按 `.btn-next` 逐节） |
| `*.gdufemooc.cn` | 同上 | 同上（学校白标实例，路径一致） |

不在这些路径下时，面板只会打一行「当前页面非刷课页面」并复位按钮，不会乱点。

## 4. 快速开始

1. **装脚本管理器**：Tampermonkey（Chrome / Edge / Firefox 均可）。
2. **导入脚本**：新建脚本 → 清空模板 → 粘贴构建产物 `雨课堂刷课助手-3.6.2.user.js` 全文 → `Ctrl+S` 保存。
   > 产物在本地 `dist/`，由 `src/` 拼装生成（见 [§9 构建](#9-开发与构建)）。脚本头部已声明 `@require` 的 CDN 依赖，
   > 首次加载需要能访问 `cdn.jsdelivr.net` / `cdnjs.cloudflare.com` / `unpkg.com`。
3. **打开课程**：进到雨课堂的课程学习页，右上会出现「雨课堂刷课助手」面板（拖到顺手的位置，位置会记住）。
4. **按需配置**：点「设置」→ 填 AI 接口（要答题才需要）、选倍速/静音、选人机验证策略 →「保存并关闭」。
5. **点「开始刷课」**：进到课程页后点一次即可，后续跨页跳转由脚本自己续上。

## 5. 设置项

**AI 接口**（答题 / 识题 / 讨论共用一份）

| 字段 | 默认 | 备注 |
|---|---|---|
| API 地址 | `https://api.deepseek.com/chat/completions` | 任意 OpenAI / Anthropic 兼容服务 |
| API Key | 空 | 只保存在本机 `localStorage` |
| 模型 | 空 | 截图识题需要支持图片输入的模型 |
| 接口格式 | OpenAI | 可选 Anthropic（会自动带 `anthropic-version`） |
| 认证方式 | Bearer Token | 可选 `X-API-Key` |

改完先点「测试连接」，再「保存并关闭」。

**播放与行为**

| 项 | 默认 | 说明 |
|---|---|---|
| 倍速 | 2（范围 0.25–4，步进 0.25） | 立即生效，播放中也会被持续校正 |
| 自动静音 | 开 | — |
| 人机验证 | 跳过当前章节 | 另一选项是「停下等待」，手动拖完滑块后脚本继续当前节 |
| 自动作答作业和题目 | 关 | 打开后作业/测验交给模型 |
| 图文 / 讨论自动回复 | 关 | 发一句生成内容到讨论区 |
| 快速模式 | 关 | 跳过读题与点击等待；更快，但更容易撞上平台核验，非必要不建议开 |

## 6. 工作原理

```
                    ┌─────────────────────────────┐
   页面加载 ───────▶│ boot()：等挂载点 → 建面板    │
   (@document-start)└──────────────┬──────────────┘
                                   │ 点击「开始刷课」
                    ┌──────────────▼──────────────┐
                    │ start()：按 URL 分发三条链路 │
                    └───┬──────────┬──────────┬───┘
        /ai-workspace/  │  /v2/web │  /pro/lms│
        lms-graph/*     │          │          │
              ▼         ▼          ▼          ▼
      AiWorkspaceRunner  V2Runner   Pro*Runner
              │              │          │
              └──────┬───────┴──────────┘
                     ▼
   ┌──────────┬──────────┬───────────┬──────────┐
   │ Player   │ Store    │ YktApi    │ Solver   │
   │ 倍速静音 │ 本地记忆 │ 平台进度  │ 答题/OCR │
   └──────────┴──────────┴───────────┴──────────┘
```

几个关键口径（都是踩过坑之后改成的）：

- **进度以平台记账为准**。「播放器播到结尾」不等于平台记满 100%：平台按 `timeupdate` 采样、只把连续向前的一小步并进
  `result` 区间表，拖过去的跨度不算数（真实抓包里 `last_point` 已到 1173.8 ≥ 时长 1173.0，`rate` 仍只有 0.7765）。
  所以脚本读观看日志算缺口、逐段补播、补完复读日志确认真的涨了，没涨才降速重试；接口拿不到时才退回「按 rate 从尾部估」的老口径。
- **「点不进去」不等于「没有下一节」**。侧栏项存在但点击不导航（考试节点常见：弹窗 / 新标签 / 权限拦截）会记成
  `lastOpenFailure`，收尾时与「确实没刷完」分开报。
- **收尾一律复位按钮**。任何终态（离开页面、认不出知识点、本节没播完、轮次超限、真没刷完）都会把按钮从「刷课中…」复位，
  不会出现「再点开始被当成重复启动忽略」。
- **识别不了就明说**。抓不到题、OCR/截图全失败、接口 404，都会在面板日志里写一条，而不是静默 `i++` 让题号与页面脱钩。

## 7. 数据与隐私

- **没有作者服务器，没有埋点**。脚本不向任何自建端点上报数据。
- **本地存储**：只写自己的 `localStorage`——刷课进度、AI 配置、倍速与静音、功能开关、跨页恢复标记、刷课轨迹、面板位置。
  想清干净：面板「更多 → 清除进度缓存」，或手动删这些键：

  ```
  [脚本]刷课进度信息   ykt_ai_conf   ykt_playback_conf   pro_lms_classCount
  ykt_feature_conf     ykt_pending_auto_start   ykt_trail   ykt_panel_rect
  ```

- **身份信息运行时现取**：`user_id` / `uv-id` / `csrftoken` 都从当前页面的 cookie 与站点全局变量读，脚本里没有任何硬编码凭据、学号或姓名。
- **AI 请求只发到你填的地址**：开启答题/识题/讨论时，题干文本、选项、必要的页面截图会发往你配置的 API
  （默认 DeepSeek）。这是使用该功能的前提，介意就保持功能开关关闭。
- **网络出口**：`yuketang.cn`、`api.deepseek.com`、`cn.bing.com`（检索）、`api.anthropic.com`、`cdn.jsdelivr.net`、
  `cdnjs.cloudflare.com`、`unpkg.com`。脚本头部目前写了 `@connect *`，属于偏宽的写法，可以按上面这份清单收窄。
- **依赖**：`opentype.js`、`html2canvas`、`tesseract.js` 通过 `@require` 从公共 CDN 加载，仅在用到对应功能时消耗。

## 9. 开发与构建

源码不是可以直接运行的单文件：`src/` 里 35 个模块共享同一个命名空间 `Y`，由 `tools/build-userscript.js`
按 `manifest.json` 的数组顺序拼回一个 `(() => { 'use strict'; const Y = {}; … Y.boot(); })();`。
模块顺序只由数组顺序与 `loadAfter` 表达，文件名不带编号前缀；装配入口一律叫 `index.js`。

```powershell
cd tools
npm install        # 首次：acorn、eslint-scope
npm run build      # → dist/雨课堂刷课助手-3.6.2.user.js + dist/build-report.json
npm run verify     # → dist/migration-parity.json（与旧单文件的等价校验）
```

构建会挡下这些错误（任一命中即退出码 1，**不要**发布产物）：

- 模块缺 `((Y) => {` / `})(Y);` 外壳，或 `node --check` 语法失败；
- 剥注释/清理改动了代码 token（删的必须只有注释和空白；产物 body 的注释 token 数必须为 0）；
- 产物头部与 `userscript.header.txt` 不一致，或外壳、入口被改动（`Y.boot();` 必须恰好出现一次）；
- 用了没有导出到 `Y` 的成员，或模块加载顺序不满足 `loadAfter`；
- `Config.version` 与 `manifest.version` 不一致（面板标题读的是前者）。

产物是**单文件、删注释**的：想给用户留说明，写进 `@description` 或面板文案，不要指望源码注释活着到产物里。
更细的模块地图、三种拆分模式（对象分片 / class mixin / 整语句）与新增模块步骤见 [`src/README.md`](src/README.md)。

**回归**：`verify/` 用 jsdom 复刻平台的侧栏、播放器与进度接口，跑 21 个场景（含「只剩期末考试」「点了不切换」「接口挂掉」
这类回归），断言的是**面板到底弹了什么、按钮在什么状态**，而不只是日志文本。

## 10. 常见问题

**面板不出现？**
先看 `<html>` 有没有 `data-ykt-helper` 属性：有值说明脚本已运行，是面板被隐藏或被盖住（全屏场景见下）；
没有值说明脚本没跑起来——检查 Tampermonkey 是否启用、URL 是否命中 `@match`、有没有别的脚本报错。

**全屏播放时面板不见了？**
3.6.1 起全屏会把面板搬进全屏层继续显示，搬运替换元素时保留状态；如果还是丢，刷新一次让可见性兜底逻辑重新挂载。

**提示「请求被篡改猴拦截」？**
API 域名不在脚本头部的 `@connect` / 管理器白名单里。在 Tampermonkey 里放行该域名，或把地址改回已授权的域名。

**视频明明播完了，进度还是没满？**
平台按「已观看区间并集」记账，拖过的片段不算。脚本会按观看日志逐段补播；如果日志接口不可用，只能退回从尾部估的老口径
（缺口在中间时补不到，属已知限制）。

**提示「平台上还差 N 节没记满」？**
这是「真没刷完」分支，不是刷完。面板日志里有每节的平台进度与点击失败原因（`点击目标不可用` / `切换失败` / `安全核验`）。

**弹窗说「期末考试」要手动完成？**
考试类节点脚本不代做。把视频、作业这些做完后自己进去考就好。

**AI 答题不工作？**
设置里先「测试连接」。常见原因：key 无效、模型名不对、接口格式选错（OpenAI / Anthropic）、
第三方兼容服务不接受图片输入（截图识题会自动退回本地 OCR）。

**想更快？**
可以开「快速模式」，但它跳过了读题与点击等待，撞上平台核验的概率明显上升，出问题先关掉它。

## 11. 已知边界

| 项 | 现状 |
|---|---|
| 考试 / 补考节点 | 不代做，只点名提醒手动完成 |
| 刷完彩带与弹窗 | 只接在 `ai-workspace/lms-graph/*` 链路；`v2/web` 与 `pro/lms` 仍是文字提示 + 「刷完啦~」按钮 |
| 「只差一份作业」这类收尾 | 判据依赖侧栏状态文本，平台改文案时需要跟着调选择器 |
| 观看日志接口不可用 | 补刷退回「按 rate 从尾部估」，中间缺口补不到 |
| 平台前端改版 | 侧栏、播放器、题型容器都是 DOM/接口双判据，改版后可能要重新对齐选择器 |
