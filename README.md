## 🌟 优势全景

<a id="gap-replay"></a>

### 🎯 1. 根据上游数据定点补刷「未上报的视频段」（看家本领）

真机上最常见的坑：**视频明明播到结尾，平台只记 77%**。抓包实证 —— `last_point` 已经 1173.8（≥ 时长 1173.0），
`rate` 却只有 `0.7765`。原因不是「没播完」，而是平台按 `timeupdate` 采样、**只把连续向前的一小步并进 `result` 区间表**，
被拖过去的那几段从来没真播过，平台不认（前端弹窗原话：「观看时有拖拽行为，拖拽部分显示未观看」）。

所以脚本不去猜「还差多少秒」，而是直接问平台「**已看的是哪几段**」：

```text
GET /video-log/detail/?classroom_id=…&user_id=…&video_id=…
  → data.heartbeat = {
      rate: 0.9369, video_length: 1173.0, completed: 1,
      result: [{s:0,e:644},{s:650,e:752},{s:822,e:1175}],   ← 已观看区间的「并集」
      last_point: 1058.4, cumulative_watch_length: 3644
    }

已看 = union(result)                → 644 + 102 + 353 = 1099 秒
缺口 = [0, 1173] − 已看              → 644–650、752–822（就是弹窗里灰色标成「未观看」的那几段）
补刷 = 逐段 seek 到 s，按真实播放播到 e + 0.5 秒
核对 = 再读一次日志，看缺口秒数有没有真的变小
```

**闭环流程**（`src/runners/workspace/credit.js` + `src/progress/ledger.js`）：

1. 🔍 读 `/video-log/detail/`，把 `result` 规整成「升序、合并、夹在 `[0, length]`」的区间表；
   小于 **1.5 秒** 的洞按心跳采样误差忽略，不浪费时间去补。
2. 🧮 求补集 = 缺口区间表，面板里直接写成人话：`有 3 段没看过（共 04:12）—— 10:44-10:50、12:32-13:42…`。
3. ⏱ 先等 2.5 秒再看一眼（平台约 30 秒一批心跳，刚播完那几十秒可能还在路上）。
4. ▶️ **逐段补播**：seek 到该段起点 → 播到终点 + 0.5 秒（多留半秒，防止末段采样记不上）→ 进下一段。
5. 🔁 **复读日志核对**：播完等 2 秒再读一次，`gapSeconds` 真的少了（> 0.5 秒）才算有效。
6. 🧊 一点没涨 → **降到 1 倍速再试一轮**；1 倍速也不涨就明说「平台在重播时没有继续记账」，不再空耗。最多 3 轮。

**为什么 seek 过去是安全的、而不是「作弊」**：平台记的是「连续播放到的位置」，跳过去的跨度本来就不计入。
脚本做的是**把缺口从头连续播一遍**，让平台把那几段从「未观看」翻成「已观看」——记多少仍然是平台说了算，脚本不伪造任何字段。

**这一路还带了三层保护**：

- 🛑 单段播放 **8 秒**没推进 → 判定卡住，放弃本段（不吊死整条链）。
- 🛑 单段补播超过 **2 小时** → 强制收手。
- 🛑 补播途中弹出安全核验 → **立刻停手**，不再继续播、也不再打接口（见 [不足 ①](#captcha)）。

**页面级也定点**：开跑先审一遍课程目录（`auditDirectory`），报「共 N 节 / 已记满 X / 待补 Y」，
并把**最靠前的未完成小节**设成本轮第一目标直接点过去（`priorityTarget` / `jumpToPriority`），
而不是从第 1 节从头再刷一遍。而且只有在「平台目录 vs 侧栏」逐项对上（条数 + 标题 + 类型 **0 失配**）时才敢用下标定位，
对不上就退回「进入后逐节查单节进度」，不会点错节。

> 💡 拿不到观看日志接口时（老接口 / 权限不足）自动退回 3.4.0 的「按 `(1-rate)×时长` 从尾部估着补」，
> 功能不倒退，但**位置是猜的、中间缺口补不到**，属已知限制（见 [不足 ③](#limits)）。

### 📊 2. 进度口径 = 平台的记账，而不是播放器的状态

- 侧栏的完成态只有图形：100% 是对勾图标、部分完成是纯 CSS 圆环（`.status-pie --p:79`，没有文字）、未开始是空节点。
  扫「已完成」文字这类做法在真机上是 **0/131 命中**。
- 于是完成判定改成「**以平台进度为准，DOM 只用来导航**」；接口连续 3 次读不到就整体退回侧栏三态，主链路照样能跑。
- 判定细节：视频拿得到区间表时，「没有任何 ≥ 1.5 秒的缺口」即算满（因为区间右端常比时长多 1~2 秒，`rate` 可能 > 1，不能用 `rate ≥ 1` 当唯一判据）。

### 🔁 3. 每一步都有核对，不是「点了就算过」

| 节点 | 怎么确认真的完成 |
|---|---|
| 视频 / 音频 | 读 `rate` / 区间表；补刷后复读日志看缺口是否变小 |
| 图文 | 平台目录 `progress` → 专用完成态接口 `user_article_finish_status` → 重开一次 → 最后才用站点自己的两个请求补记 |
| 作业 / 测验 | 选项**都点到了**才标 done；找不到提交按钮就返回失败，绝不出现「面板说已交、实际没交」 |
| 讨论 | 回复长度不达标 / 残句不截断，按题目要求重来 |

### 🧩 4. 全类型串播，一条链跑到底

视频、音频、课件（含课件内视频）、图文、PDF、测验、作业、讨论按目录顺序推进；课件视频被关闭 / 销毁会**自动重开重播**；
v2 链路带 500 轮硬上限防死循环。大部分「不支持的类型」在 3.6.0 后都变成「打开即完成 + 查平台记账」。

### ⏯ 5. 断点续跑与「先补欠账」

- 跨页跳转（进课程 → 回目录）后自动恢复刷课，不用重新点开始；
- 开跑先补**最靠前**的未完成小节，欠账优先清；
- 任何终态都会把「开始刷课」按钮**复位**，不会卡在「刷课中…」让下一次点击被当成重复启动忽略。

### 🎉 6. 收尾三分支：把「刷完了」「只剩考试」「真没刷完」判开

老版本的坑：三种完全不同的结局被混成一句「没找到能切换过去的下一节」，用户以为脚本漏刷。现在：

| 情形 | 输出 |
|---|---|
| 平台目录逐节核对，全部记满 | 🎊 撒彩带（72 片 DOM 彩带）+ 弹窗「本课程已刷完」+ 按钮变「刷完啦~」 |
| 只剩考试这类脚本不代做的小节 | 🎊 同样撒彩带 + 弹窗里**点名**要手动完成哪几节 |
| 还有能自动学的小节没记满 | ⚠️「平台还差 N 节没记满，这次不是刷完：…」+ 列出每节平台多少、点不动的原因 |

「点不进去」和「没有下一节」也不再混为一谈：失败原因会记成 `点击目标不可用` / `切换失败` / `安全核验`。

### 🛡 7. 人机验证闸门：检测准、动作轻、能续跑

- **检测口径保守**：只认完整话术（`安全核验` / `按住…起` / `依次经过` / `拖动滑块` …），
  「验证码」单独出现时只在**弹窗 / 核验容器**里才算 —— 否则课程正文里的「人机交互」「验证码原理」会把整轮卡死。
- iframe 一起扫（作业常在内嵌 iframe 里），但**跳过脚本自己的面板 iframe**，不会把自己的设置标题当弹窗。
- 两种策略：**跳过当前章节**（默认）/ **停下等待**（人工拖完滑块后脚本继续当前节）。
- 一旦判定被核验拦下就**置停住标志**：不再试下一节、不再打接口、记一条 skip、复位按钮，人工处理完点「开始刷课」从当前节续跑。

### 🖥 8. 切屏拦截兼容 + 全屏兜底

- 拦 `visibilitychange` / `blur` / `pagehide`，伪造 `hidden` / `visibilityState` / `hasFocus`，连作业所在的 iframe 一起处理。
- 页面进全屏时用 `moveBefore()` **保状态**把面板搬进全屏层继续可见（真机实测：不搬时 `isConnected` 为 true、`display:block`，但一帧都不画）。
- `<html data-ykt-helper="版本号">` 留痕 —— 以后区分「脚本没跑」和「跑了但面板被盖住」，不用再靠猜。

### 🤖 9. AI 答题是可选项，而且做了不少防呆

- 支持 **OpenAI / Anthropic 两种接口格式**、**Bearer / X-API-Key 两种认证**，默认 DeepSeek，填任意兼容服务即可。
- 截图识题走多模态模型；模型不收图就**自动退回本地 OCR**（`tesseract.js`），并让后续题目直接走 OCR。
- 考试类页面的 `exam_font` 自定义字体，用 `opentype.js` 读字形、按 **SHA-1 对照表**还原成正常文字。
- 防呆：`reasoning_content` / `thinking` **只能用于诊断、永远不作为可提交答案**；输出被 token 上限截断就直接报错停止；
  OCR 失败返回哨兵字符串时**不会**被当成题目丢给模型（否则模型会按选择题瞎答并提交）。
- 讨论 / 图文回复会校验长度与残句，不会把半句话发出去。

### 🧱 10. 接口只是「更准的尺子」，坏了也不拖死流程

- 所有平台接口失败都**吞掉返回 `null`**，绝不因为一次 404 / 超时把刷课拖停。
- 连续失败 3 次自动**停用接口**，整体退回只看页面标记。
- 请求头照抄站点自己的全局拦截器（`university-id` / `uv-id` / `x-csrftoken` / `classroom-id`），
  但**身份信息全部运行时现取**（cookie + 站点全局变量），脚本里没有任何硬编码凭据、学号或姓名。

### 🔒 11. 隐私：没有作者服务器，没有埋点

- 不向任何自建端点上报数据；只写自己的 `localStorage`（进度、AI 配置、倍速、开关、跨页恢复标记、轨迹、面板位置）。
- AI 请求**只发到你填的地址**（默认 DeepSeek），题干 / 选项 / 必要截图才发，不介意就保持开关关闭。
- 一键清干净：面板「更多 → 清除进度缓存」。

### 🧪 12. 工程化：模块化源码 + 构建门禁 + 可复跑的回归台

- `src/` 35 个模块共享 `Y` 命名空间，`manifest.json` 显式声明加载顺序与 `loadAfter` 拓扑，单文件产物**删注释**。
- 构建会挡下：模块缺外壳 / 语法失败、**注释剥除改动代码 token**、产物头与 `userscript.header.txt` 不一致、
  用了没导出到 `Y` 的成员、`loadAfter` 顺序不满足、`Config.version` 与 `manifest.version` 不一致。
- `verify/` 用 jsdom 复刻平台侧栏、播放器与进度接口，跑 **21 个场景**（含「只剩期末考试」「点了不切换」「接口挂掉」
  「观看日志挂掉」「缺口在中间」「图文没上报」这类回归），断言的是**面板到底弹了什么、按钮在什么状态**，不只是日志文本。
- 同一套场景跑基线：基线 **7/21**，本项目 **21/21** —— 证明断言真的有判别力，不是摆着好看的绿灯。
- 🎧 说明：本项目的代码 **100% 由 Vibe Coding 产出**（见 [100% Vibe Coding 项目](#vibe)）。所以上面这些门禁与回归台不是装饰，
  而是让「对话写出来的代码」能被信任的唯一护栏 —— 没有它们，就没有这一节的底气。

## ⚠️ 不足与已知限制

<a id="captcha"></a>

### 🙋 ① 验证码：不支持自动校验，而且答题过程中频发

| 🧩 维度 | 现状 |
|---|---|
| 🚫 **不能自动过** | 没有滑块轨迹模拟、没有图形码 OCR、没有对接打码平台。检测到核验**只会**在两种策略里二选一：`跳过当前章节`（默认）/ `停下等待` |
| 😮‍💨 **频发** | 作业 / 测验连续作答时，平台会**反复**弹「安全核验」。一轮作业下来可能要人工过好几次 —— 长流程实际是「半自动」 |
| 🧊 一弹就停 | 核验期间脚本会停住（不点、不播、不打接口），进度不丢；人工过完点「开始刷课」从当前节续跑 |
| 🩹 能减轻但没消除 | 关掉「快速模式」（它跳过读题与点击等待，更容易撞核验）能降低触发率；但**不能保证不弹** |
| 🗺 计划 | 属长期项，不承诺时间。目前把「检测准 + 停得干净 + 能续跑」做到位，比做一个不靠谱的自动过码更有用 |

> 📌 换句话说：**脚本负责「刷课」这件重复劳动，核验这一步仍然需要你在场点一下。**
> 默认策略是「跳过当前章节」而不是死等，就是为了让你不在电脑前时脚本也能继续推进其它小节。

### 📋 其它已知限制

| # | 项 | 现状 / 影响 | 处置 |
|---|---|---|---|
| ② | 🎓 考试 / 补考节点 | 不代考、不代做 | 收尾弹窗**点名**提醒手动完成，只记一条轨迹不重复刷屏 |
| ③ | 📉 观看日志接口不可用 | 补刷退回「按 `(1-rate)×时长` 从尾部估」 | 缺口在**中间**时补不到，位置是猜的 —— 这条是硬限制，只在接口拿不到时才会发生 |
| ④ | 🧱 平台前端改版 | 侧栏、播放器、题型容器都可能换选择器 | 采用 DOM + 接口**双判据**；接口能用时不受 DOM 改版影响，接口也没了才需要跟着改 |
| ⑤ | ⏳ 平台完成态滞后 | 侧栏常晚一节（有时要回目录才同步） | 结论只认平台目录接口，侧栏仅作参考；不会用滞后的侧栏误报「没刷完」 |
| ⑥ | 🎊 彩带 / 弹窗 | 只接在 `ai-workspace/lms-graph/*` 主链路 | `v2/web` 与 `pro/lms` 仍是文字提示 +「刷完啦~」按钮（那两条链路没有平台目录可逐节核对） |
| ⑦ | 🔤 本地 OCR 精度 | 模型不收图时才用 `tesseract.js` | 识别失败**不猜答案**，记一条并跳过该题，题号不与页面脱钩 |
| ⑧ | 🌐 `@connect *` | 授权面偏宽 | 脚本头部目前写的是 `*`，可按 [出口清单](#privacy) 收窄 |
| ⑨ | 🧰 三个老测试套件跑不了 | `extra-tests.js` / `audit-fix-tests.js` / `forum-reply-tests.js` 靠**源码注释锚点**切片，而产物注释清零、模块化后锚点不再相邻 | 属工具链债，需改成读 `src/` 各模块；`verify/run.js` 的 21 场景不受影响 |
| ⑩ | 🏫 域名覆盖 | 只认 `*.yuketang.cn` 与 `*.gdufemooc.cn`（路径一致的白标实例同样可用） | 其它白标域名需自己加 `@match` |

## 1. 这是什么 ✨

在雨课堂的课程学习页注入一个可拖动的控制面板，点「开始刷课」之后，脚本接管播放器并按目录逐节推进：

- 📺 视频自动播完就换下一节，倍速与静音按设置执行，被平台改回去会自动重设；
- 📑 课件（PPT / 课件内视频）按设定间隔翻页、等内嵌视频播完；
- 📄 图文、PDF、讨论这些「点开即完成」的节点，打开后等平台记账；
- 🎯 视频播到头但平台没记满时，按平台的观看日志算出**真实缺口**，**逐段定点补播**再核对（见 [优势 ①](#gap-replay)）。

也可以只当个「倍速 + 静音 + 进度查看器」用：面板里的倍速 / 静音 / 快速模式随手可切，不点开始就不会接管流程。

**它不是**：考试代做工具（考试 / 补考一类的节点脚本明确不代做，只在收尾时点名提醒），不是刷分器，
也不会把任何数据发到作者自己的服务器（见 [§7 数据与隐私](#privacy)）。

## 6. 工作原理 🔍

```
                    ┌─────────────────────────────┐
   页面加载 ───────▶│ boot()：等挂载点 → 建面板    │
   (@document-start)└──────────────┬──────────────┘
                                   │ 点击「开始刷课」
                    ┌──────────────▼──────────────┐
                    │ start()：按 URL 分发三条链路 │
                    └───┬──────────┬──────────┬───┘
        /ai-workspace/  │  /v2/web │  /pro/lms│
        lms-graph/*     │          │          │
              ▼         ▼          ▼          ▼
      AiWorkspaceRunner  V2Runner   Pro*Runner
              │              │          │
              └──────┬───────┴──────────┘
                     ▼
   ┌──────────┬──────────┬───────────┬──────────┐
   │ Player   │ Store    │ YktApi    │ Solver   │
   │ 倍速静音 │ 本地记忆 │ 平台进度  │ 答题/OCR │
   └──────────┴──────────┴───────────┴──────────┘
```

补刷时的内部时序：

```
读日志 videoLog() → 已看区间 ∪ → 缺口 = 补集
        │
        ├─ 无缺口 ────────────────────────────▶ ✅ 记账已满，进下一节
        │
        └─ 有缺口 → 逐段：seek(s) → 播到 e+0.5 → 读日志
                                   │
                    缺口变小 ──────┴────── 缺口没变
                       │                      │
                       ▼                      ▼
                  继续下一段 / 完成     降 1 倍速重试（最多 3 轮）→ 仍不涨则收手
```

几个关键口径（都是踩过坑之后改成的）：

- **进度以平台记账为准**。「播放器播到结尾」不等于平台记满 100%：平台按 `timeupdate` 采样、只把连续向前的一小步并进
  `result` 区间表，拖过去的跨度不算数（真实抓包里 `last_point` 已到 1173.8 ≥ 时长 1173.0，`rate` 仍只有 0.7765）。
  所以脚本读观看日志算缺口、逐段补播、补完复读日志确认真的涨了，没涨才降速重试；接口拿不到时才退回「按 rate 从尾部估」的老口径。
- **「点不进去」不等于「没有下一节」**。侧栏项存在但点击不导航（考试节点常见：弹窗 / 新标签 / 权限拦截）会记成
  `lastOpenFailure`，收尾时与「确实没刷完」分开报。
- **收尾一律复位按钮**。任何终态（离开页面、认不出知识点、本节没播完、轮次超限、真没刷完）都会把按钮从「刷课中…」复位，
  不会出现「再点开始被当成重复启动忽略」。
- **识别不了就明说**。抓不到题、OCR / 截图全失败、接口 404，都会在面板日志里写一条，而不是静默 `i++` 让题号与页面脱钩。

## 7. 数据与隐私 🔒

- 🚫 **没有作者服务器，没有埋点**。脚本不向任何自建端点上报数据。
- 💾 **本地存储**：只写自己的 `localStorage`——刷课进度、AI 配置、倍速与静音、功能开关、跨页恢复标记、刷课轨迹、面板位置。
  想清干净：面板「更多 → 清除进度缓存」，或手动删这些键：

  ```
  [脚本]刷课进度信息   ykt_ai_conf   ykt_playback_conf   pro_lms_classCount
  ykt_feature_conf     ykt_pending_auto_start   ykt_trail   ykt_panel_rect
  ```

- 🪪 **身份信息运行时现取**：`user_id` / `uv-id` / `csrftoken` 都从当前页面的 cookie 与站点全局变量读，
  脚本里没有任何硬编码凭据、学号或姓名。
- 🤖 **AI 请求只发到你填的地址**：开启答题 / 识题 / 讨论时，题干文本、选项、必要的页面截图会发往你配置的 API
  （默认 DeepSeek）。这是使用该功能的前提，介意就保持功能开关关闭。
- 🌐 **网络出口**：`yuketang.cn`、`api.deepseek.com`、`cn.bing.com`（检索）、`api.anthropic.com`、`cdn.jsdelivr.net`、
  `cdnjs.cloudflare.com`、`unpkg.com`。脚本头部目前写了 `@connect *`，属于偏宽的写法，可以按上面这份清单收窄。
- 📦 **依赖**：`opentype.js`、`html2canvas`、`tesseract.js` 通过 `@require` 从公共 CDN 加载，仅在用到对应功能时消耗。

<a id="build"></a>

## 9. 开发与构建 🛠

源码不是可以直接运行的单文件：`src/` 里 35 个模块共享同一个命名空间 `Y`，由 `tools/build-userscript.js`
按 `manifest.json` 的数组顺序拼回一个 `(() => { 'use strict'; const Y = {}; … Y.boot(); })();`。
模块顺序只由数组顺序与 `loadAfter` 表达，文件名不带编号前缀；装配入口一律叫 `index.js`。

```powershell
cd tools
npm install        # 首次：acorn、eslint-scope
npm run build      # → dist/雨课堂刷课助手-3.6.3.user.js + dist/build-report.json
npm run verify     # → dist/migration-parity.json（与旧单文件的等价校验）
```

构建会挡下这些错误（任一命中即退出码 1，**不要**发布产物）：

- 模块缺 `((Y) => {` / `})(Y);` 外壳，或 `node --check` 语法失败；
- 剥注释 / 清理改动了代码 token（删的必须只有注释和空白；产物 body 的注释 token 数必须为 0）；
- 产物头部与 `userscript.header.txt` 不一致，或外壳、入口被改动（`Y.boot();` 必须恰好出现一次）；
- 用了没有导出到 `Y` 的成员，或模块加载顺序不满足 `loadAfter`；
- `Config.version` 与 `manifest.version` 不一致（面板标题读的是前者）。

产物是**单文件、删注释**的：想给用户留说明，写进 `@description` 或面板文案，不要指望源码注释活着到产物里。
更细的模块地图、三种拆分模式（对象分片 / class mixin / 整语句）与新增模块步骤见 [`src/README.md`](src/README.md)。

**回归**：`verify/` 用 jsdom 复刻平台的侧栏、播放器与进度接口，跑 21 个场景（含「只剩期末考试」「点了不切换」「接口挂掉」
「观看日志挂掉」「缺口在中间」「图文没上报」这类回归），断言的是**面板到底弹了什么、按钮在什么状态**，而不只是日志文本。
同一套场景跑基线只有 7/21 通过 —— 断言有判别力。

## 10. 常见问题 ❓

**面板不出现？**
先看 `<html>` 有没有 `data-ykt-helper` 属性：有值说明脚本已运行，是面板被隐藏或被盖住（全屏场景见下）；
没有值说明脚本没跑起来——检查 Tampermonkey 是否启用、URL 是否命中 `@match`、有没有别的脚本报错。

**一直要我拖滑块，能自动过吗？**
🙅 **不能**。验证码自动校验目前不支持（见 [不足 ①](#captcha)）：
没有轨迹模拟、没有图形码识别、也没接打码平台。脚本能做的是**检测准 + 停得干净 + 能续跑**：
默认策略「跳过当前章节」，人工过掉核验后点「开始刷课」从当前节继续；想让它原地等就切到「停下等待」。
作业 / 测验连答时平台弹得比较勤，关掉「快速模式」能少撞几次，但不能保证不弹。

**全屏播放时面板不见了？**
3.6.1 起全屏会把面板搬进全屏层继续显示，搬运替换元素时保留状态；如果还是丢，刷新一次让可见性兜底逻辑重新挂载。

**提示「请求被篡改猴拦截」？**
API 域名不在脚本头部的 `@connect` / 管理器白名单里。在 Tampermonkey 里放行该域名，或把地址改回已授权的域名。

**视频明明播完了，进度还是没满？**
平台按「已观看区间并集」记账，拖过的片段不算。脚本会按观看日志**逐段定点补播**；
只有日志接口不可用时才退回从尾部估的老口径（此时缺口在中间补不到，属已知限制）。

**补刷为什么有时只补一两分钟，有时补好几分钟？**
因为补的是**真实缺口**，不是按比例估的秒数：弹窗里灰色那几段有多长就补多长。缺口在片头就补片头，不会再白播一遍已经看完的尾巴。

**提示「平台上还差 N 节没记满」？**
这是「真没刷完」分支，不是刷完。面板日志里有每节的平台进度与点击失败原因（`点击目标不可用` / `切换失败` / `安全核验`）。

**弹窗说「期末考试」要手动完成？**
考试类节点脚本不代做。把视频、作业这些做完后自己进去考就好。

**AI 答题不工作？**
设置里先「测试连接」。常见原因：key 无效、模型名不对、接口格式选错（OpenAI / Anthropic）、
第三方兼容服务不接受图片输入（截图识题会自动退回本地 OCR）。

**想更快？**
可以开「快速模式」，但它跳过了读题与点击等待，撞上平台核验的概率明显上升，出问题先关掉它。
